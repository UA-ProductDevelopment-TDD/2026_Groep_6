# 2026_Groep_6

Product Development project of team 6 (University of Antwerp).

**New here? Read [HOW-TO-GIT.md](HOW-TO-GIT.md) first.**

## Project structure

| Folder | What goes in it | Who |
|---|---|---|
| [`hardware/`](hardware/) | Firmware, wiring, CAD exports | Hardware pair |
| [`software/`](software/) | Code that controls the robot | Software pair |
| [`ui/`](ui/) | Interface code and designs | UI pair |
| [`docs/`](docs/) | Reports, meeting notes, research | Everyone |

## How we work

- Nobody pushes to `main` directly. Everyone works on a **branch** and opens a **Pull Request**.
- Michael (git manager) reviews and merges every Pull Request.
- Questions or Git problems → ask Michael.
